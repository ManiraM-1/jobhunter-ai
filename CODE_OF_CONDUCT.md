# Code of conduct

This project helps people find jobs, often at a stressful time in their lives. Treat everyone here the way you'd want to be treated when you're the one job-hunting.

- Be respectful and assume good intent. Critique code and ideas, not people.
- No harassment, discrimination, or personal attacks, whatever someone's background, college, experience level or language.
- Never post anyone's personal data (CVs, phone numbers, salaries) in issues or PRs. Anonymise examples.
- Keep discussion on topic and in English, or in another language everyone in the thread is comfortable with.

Report problems to the maintainer through GitHub (open a private security advisory or message the maintainer). Maintainers may edit or remove content and block contributors who break these rules.
